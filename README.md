# Dostaffkin

Одностраничное веб-приложение на Angular с маршрутизацией, формами и toast-уведомлениями.

## Возможности

- Клиентская навигация через Angular Router.
- Работа с формами через Angular Forms.
- Отображение уведомлений с помощью `ngx-toastr`.
- Реактивная обработка данных и асинхронных операций через RxJS.
- Разработка, сборка и запуск тестов через npm-скрипты.

> Серверная часть, база данных и API-эндпоинты в доступных конфигурационных файлах не указаны.

## Технологический стек

- TypeScript
- Angular `21.1.1`
- Angular Router и Forms
- RxJS `7.8.2`
- `ngx-toastr` `20.0.4`
- Angular CLI / `@angular/build`

- JSDOM `27.4.0`
- Prettier
- npm `10.9.2`

## Установка

Требуется Node.js с поддержкой Angular 21.

    npm install

## Запуск

Запуск dev-сервера:

    npm start

Приложение будет доступно по адресу `http://localhost:4200`.

## Команды

| Команда | Назначение |
|---|---|
| `npm start` | Запуск dev-сервера |
| `npm run build` | Production-сборка |
| `npm run watch` | Сборка в режиме отслеживания изменений |
| `npm test` | Запуск тестов |
| `npm run ng` | Вызов Angular CLI |
